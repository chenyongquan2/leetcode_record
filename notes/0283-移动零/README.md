# 283. 移动零

- 难度：容易　|　CodeTop 频率：67
- 链接：https://leetcode.cn/problems/move-zeroes/

## 思路

- **快慢指针，两段式**：第一遍 `fast` 探路，遇到非零元素就压到 `nums[slow]` 并让 `slow` 前移——扫完后 `nums[0..slow-1]` 是保持相对顺序的全部非零元素；第二遍把 `slow` 到结尾的位置全部写 0。
- 本质是"移除元素"（第 27 题移除所有 0）加一步"尾部补 0"，和第 26 题去重是同一个快慢指针家族：`slow` 维护已处理好的前缀，`fast` 负责探路。
- 注意这里赋值是"先 `nums[slow] = nums[fast]` 再 `slow += 1`"，与 26 题的"先 `slow += 1` 再赋值"顺序不同——因为本题 `nums[0..slow-1]` 才是有效区，而 26 题 `nums[0..slow]` 是有效区，写代码前先想清楚不变量。

## 复杂度

- 时间：O(n)
- 空间：O(1)

## 易错点 / 回顾记录

- 2026-08-31：首次完成。第二遍补 0 直接复用 `slow` 从当前位置写到结尾即可，不需要重新数有几个零；相对顺序天然保持（非零元素按原顺序依次压入），不要想着用交换以外的花活破坏顺序。
