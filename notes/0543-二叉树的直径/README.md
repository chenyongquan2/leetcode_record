# 543. 二叉树的直径

- 难度：容易　|　CodeTop 频率：82
- 链接：https://leetcode.cn/problems/diameter-of-binary-tree/

## 思路

- **[104 求深度](../0104-二叉树的最大深度/README.md) 的升级版，"后序遍历顺便干活"的经典题**：直径 = 某个节点的 左子树深度 + 右子树深度 的最大值，但这个"最长路径"不一定经过根，所以要在**每个节点**的后序位置都算一遍、用外部变量 `ans`（`nonlocal`）打擂台。
- 本写法按**节点数**记路径：`dia = 1 + lh + rh`（当前节点 + 左右两臂），`getDepth` 返回的也是节点数深度 `1 + max(lh, rh)`；题目要的直径是**边数**，所以最后 `return ans - 1`。
- 也可以从头就按边数算（空节点深度记 -1 或叶子记 0），省掉末尾的 -1，但口径必须全程统一——混用节点数/边数是这题最常见的错法。
- 递归函数的返回值（深度，给父节点用）和要求的答案（直径，挂在外部变量上）**不是同一个东西**，这是本题和 104 的本质区别。

## 复杂度

- 时间：O(n)（每个节点访问一次）
- 空间：O(h)（递归栈深度 = 树高，最坏 O(n)）

## 易错点 / 回顾记录

- 2026-09-01：首次完成，掌握程度 3 星。注意：① 直径可能不经过根，必须每个节点都更新 `ans`；② 节点数口径要靠 `ans - 1` 转成边数；③ 内层函数改外部变量记得 `nonlocal`。
