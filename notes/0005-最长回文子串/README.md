# 5. 最长回文子串

- 难度：中等　|　CodeTop 频率：356
- 链接：https://leetcode.cn/problems/longest-palindromic-substring/

## 思路

- **中心扩散双指针**：找回文串的难点在于回文串的长度可能是奇数也可能是偶数。奇数长度有一个中心字符，偶数长度可以认为有两个中心字符。
- 先实现辅助函数 `getPalindrome(s, lo, hi)`：在 `s` 中寻找以 `s[lo]` 和 `s[hi]` 为中心向两端扩散的最长回文串，扩散终止后回文串是 `s[lo+1:hi]`（因为退出循环时 `lo`、`hi` 已各多走了一步）。
- 主循环枚举每个下标 `i`，分别以 `(i, i)`（奇数中心）和 `(i, i+1)`（偶数中心）各扩一次，取历次结果中最长者。

## 复杂度

- 时间：O(n²)（n 个中心 × 每次扩散最多 O(n)）
- 空间：O(1)（不计切片产生的临时子串；若计入则单次扩散返回 O(n) 拷贝）

## 知识点：回文串中心扩散要同时枚举奇偶两种中心

回文串长度可为奇数或偶数：奇数回文有单一中心字符，偶数回文的中心是相邻两个字符。因此对每个下标 `i` 要分别以 `(i, i)` 和 `(i, i+1)` 为起点各扩散一次，否则会漏掉一半情况（如 `"cbbd"` 里的 `"bb"`）。扩散循环 `while lo>=0 and hi<len(s) and s[lo]==s[hi]` 退出时两指针已越界一步，结果取 `s[lo+1:hi]`。
