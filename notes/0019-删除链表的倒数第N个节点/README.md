# 19. 删除链表的倒数第N个节点

- 难度：中等　|　CodeTop 频率：184
- 链接：https://leetcode.cn/problems/remove-nth-node-from-end-of-list/

## 思路

- 删除倒数第 n 个节点 = 先找到**倒数第 n+1 个节点**（被删节点的前驱），然后 `x.next = x.next.next` 跳过它。
- 找倒数第 k 个节点用**快慢指针**：快指针先走 k 步，然后快慢一起走；快指针到达末尾 `None` 时，慢指针恰好停在倒数第 k 个。
- **虚拟头节点防空指针**：若链表共 5 个节点、要删倒数第 5 个（即头节点），那需要找倒数第 6 个节点，而头节点前面没有节点了——加一个 dummy 挂在最前面，这种情况就能正常删除。从 dummy 出发找倒数第 n+1 个，前面多挂节点不影响"倒数"的计数。

## 复杂度

- 时间：O(L)，L 为链表长度，快慢指针各扫一遍
- 空间：O(1)

## 易错点 / 回顾记录
