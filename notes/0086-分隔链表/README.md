# 86. 分隔链表

- 难度：中等　|　CodeTop 频率：22
- 链接：https://leetcode.cn/problems/partition-list/

## 思路

- 用**两个虚拟头节点**把原链表拆成两条：`dummy1` 挂所有 `< x` 的节点，`dummy2` 挂所有 `>= x` 的节点；`p1` / `p2` 分别是两条新链的尾指针。
- `p` 遍历原链表，按节点值大小把当前节点挂到对应链的尾部。
- 关键一步：每挂完一个节点要**主动断链**（先记住 `p.next`，再置 `p.next = None`，然后走向记下的节点）——否则挂过去的节点还拖着原链表的后继，两条链会交织成环或带上多余节点。
- 遍历结束后 `p1.next = dummy2.next` 把「>= x」链整体接到「< x」链后面，返回 `dummy1.next`。相对顺序天然保留（稳定分区）。

## 复杂度

- 时间：O(n)，原链表遍历一次
- 空间：O(1)，节点原地复用，只有常数个指针
