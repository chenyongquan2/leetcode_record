# 144. 二叉树的前序遍历

- 难度：容易　|　CodeTop 频率：84
- 链接：https://leetcode.cn/problems/binary-tree-preorder-traversal/

## 思路

- **递归遍历（"遍历"思路）**：定义 `travel(root)` 走遍整棵树，在**进入节点的时刻**（前序位置）把 `root.val` 追加到外部结果列表 `res`，然后递归左、右子树。
- 用内层函数 + 闭包共享 `res`，避免把列表在参数里传来传去。
- 与 [104](../0104-二叉树的最大深度/README.md) 对比正好是二叉树两大套路的两个代表：104 是"分解问题"（靠返回值合并子树答案，逻辑在后序位置），本题是"遍历"（靠外部变量收集，逻辑在前序位置）。中序/后序遍历只需把 `res.append` 挪到递归左子树之后/两个递归都结束之后。

## 复杂度

- 时间：O(n)（每个节点访问一次）
- 空间：O(h)（递归栈深度 = 树高，最坏 O(n)；res 不计）
