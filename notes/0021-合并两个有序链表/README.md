# 21. 合并两个有序链表

- 难度：容易　|　CodeTop 频率：333
- 链接：https://leetcode.cn/problems/merge-two-sorted-lists/

## 思路

- 建**虚拟头节点** `dummy`，规避「结果链表头节点需要特判」的问题；`p` 始终指向结果链表的尾部。
- `p1` / `p2` 双指针分别在两条链上走，每轮比较两者的值，把**较小的节点**接到 `p.next`，该指针前移一步，`p` 也前移。
- 循环退出时（至少一条链走完），把**没走完的那条链整段接上**即可——因为它本身已有序。
- 返回 `dummy.next`（不是 `dummy`）。

## 复杂度

- 时间：O(m + n)，两条链各遍历一次
- 空间：O(1)，只用了常数个指针，节点原地复用
