# 104. 二叉树的最大深度

- 难度：容易　|　CodeTop 频率：91
- 链接：https://leetcode.cn/problems/maximum-depth-of-binary-tree/

## 思路

- **递归定义**：一棵树的最大深度 = 1 + max(左子树最大深度, 右子树最大深度)；空节点（`root is None`）深度为 0，即递归出口。
- 这是"分解问题"思路的后序遍历：先拿到左右子树的答案 `ld`、`rd`，回溯时合并出当前节点的答案。二叉树很多题都是这个骨架（先递归左右、再在返回时做事）。

## 复杂度

- 时间：O(n)（每个节点访问一次）
- 空间：O(h)（递归栈深度 = 树高，最坏退化成链表为 O(n)）
