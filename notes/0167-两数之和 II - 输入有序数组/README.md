# 167. 两数之和 II - 输入有序数组

- 难度：容易　|　CodeTop 频率：17
- 链接：https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/

## 思路

- **左右双指针相向收缩**：利用数组已升序这个前提，`lo` 指头、`hi` 指尾。两数之和等于 `target` 直接返回；和偏大说明右边太大，`hi` 左移；和偏小说明左边太小，`lo` 右移。
- 正确性依据：每次移动都只排除"不可能成为答案"的那一端——比如 `sum > target` 时，`numbers[hi]` 与任何剩余元素配对都只会更大，所以 `hi` 可以安全丢弃。
- 与第 1 题（无序两数之和）对比：无序只能哈希表 O(n) 空间；有序换来 O(1) 空间的双指针。题目要求返回下标从 1 开始，所以返回 `[lo+1, hi+1]`。
